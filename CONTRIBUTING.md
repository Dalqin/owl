# Contributing

Issues are welcome: bug reports, feature requests, and ideas for making modded Morrowind easier to set up.

**Pull requests are not accepted.** This keeps the copyright in the code with a single author, which keeps licensing simple. Please describe the behavior you want or the problem you hit rather than pasting code; changes are implemented by the maintainer.
